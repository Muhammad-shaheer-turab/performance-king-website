Help

The same help is inside the app: tap Help on its first screen.

How it works

  1. Nothing disappears. Whatever Performance King removes goes to its recycle bin first, in the folder it came from. You can put it back.
  2. Pack away. Makes files take less room, like vacuum-packing clothes. Put one back and it is exactly the same file again.
  3. Duplicates. The same file saved twice, often from WhatsApp. Keep one; the spare goes to the bin.
  4. Free space. Deletes spare copies from the bin to give you room. The last copy of a file is never deleted.
  5. Back up. Copies your files to an SD card, a USB drive or a folder you choose, so they survive a lost or broken phone.

Words you will see

  • Pack away: Store a file in less room. Nothing inside it changes.
  • Packed away: Files stored that way. Your gallery and other apps cannot see them until you put them back.
  • Put back: Return a file to where it was, exactly as it was.
  • Recycle bin: Where removed files wait. Nothing in it is lost.
  • Spare copy: A file with a twin elsewhere on the phone, or with a packed copy.
  • Only copy: The last copy of a file. Performance King never deletes it.
  • Free space: Delete spare copies from the bin to get the room back.
  • Back up: Copy files off the phone to keep them safe.
  • Keep originals: A folder rule: Performance King leaves that folder exactly as it is.

Questions

Where do removed files go?

Into the recycle bin, in the folders they came from. Open Recycle bin, tick them and tap Put back.

How do I get a packed file back?

Open Pack away files, then Packed away. Tick it and tap Put back. It returns to its folder exactly as it was.

Why will some files not leave the bin?

They are the only copy, and Performance King never deletes the last copy of a file. If you really want one gone, put it back and delete it in your phone’s Files app.

What should I do before uninstalling?

Put back everything you packed (Pack away files, Packed away, Put back all). Uninstalling keeps the hidden “.PerformanceKing” folder, but only Performance King can put packed files back.

Another app deleted the “.PerformanceKing” folder. Can I get my files back?

Only from your own backup. That folder holds your packed files and the recycle bin, which is why a backup away from the phone matters.

Why does it need “All files access”?

To find copies and large files in every folder, and to put files back exactly where they were. It has no internet access, so nothing it reads leaves your phone.

Does it upload my files?

No. It cannot use the internet. Files leave the phone only when you back them up or send them somewhere yourself.

Will it make my phone faster?

It frees storage space. A full phone often works badly, so space can help, but Performance King promises nothing about speed.
